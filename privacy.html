Lennox Privacy Policy

Last updated: 19 November 2026

Lennox is a personal assistant used by a single person (its owner) on their own computer. It is not offered to the public and has no other users.

What data Lennox accesses

With the owner's permission, Lennox reads the owner's Gmail messages and Google Calendar events. It can create Gmail drafts and calendar events only after the owner approves each one. Lennox never sends or deletes email.

How the data is used

Lennox uses this data only to sort messages and events by importance, send the owner reminders and alerts, and answer the owner's questions about their own email and calendar.

Where the data goes

All processing happens on the owner's own computer, using an AI model that runs locally. Google user data is not sold, shared with third parties, or used for advertising, and it is not sent to any server operated by Lennox. Short alert messages are delivered to the owner's own Telegram account.

Storage and deletion

A small local database of alerts and reminders, plus the Google sign-in token, is stored only on the owner's computer. The owner can delete it at any time, and can revoke Lennox's access at myaccount.google.com/permissions.

Limited Use

Lennox's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
